# The gap / needs-attention color is teal, not amber

The color that marks a folder needing an ebook is teal. It carries the gaps-to-fill count, the "needs ebook" badge, the flagged folder icon, and the per-root gap chips. Light theme uses `#0e7490` for ink and `#06b6d4` as the fill base that the soft badges tint from; dark theme uses `#22d3ee` for ink against the same `#06b6d4` base. The token keeps the name `--color-warning`: the hue changed, the role ("this needs attention") did not.

We started on amber and spent a while trying to keep it. A saturated amber (`#f5a524`) is unreadable as ink on a white surface, about 2:1, below both AA and the 3:1 large-text floor. The only amber that clears AA as light-mode text is a dark mustard near `#9a6700` (Primer's `fgColor.attention`), which reads muddy. Chasing a brighter amber confirmed there is no escape: any saturated hue bright enough to read on a dark surface is too light for white, so the foreground value always splits per theme. Brightness was never the lever, which is what sent us looking at a different hue.

The palette already spends indigo on the primary, green on success, and red on error, so a fourth role has to stay clear of all three. Teal does: it sits away from indigo and red, reads as an informational "to do" rather than a danger, and stays clean instead of muddy at the dark value light mode needs. It clears AA on both surfaces with margin (ink about 5.4:1 light and 8.8:1 dark; the soft badge label about 4.6:1 light and 6.6:1 dark). Orange was the runner-up and the only other warm option, but it drifts toward the error red, so a gap badge and an error badge can read as two warm alarms.

The one thing to watch is that teal is a cool color like the success green, and `#046b4d` is itself a teal-green. Where a teal "N gaps" chip sits beside a green "no gaps" chip they are close in hue. Rendered they stay distinguishable (teal is cyan, success is yellow-green), but if the summary chips ever feel ambiguous, fall back to the orange we set aside: `#c2410c` ink and `#f97316` fill base on light, `#fb923c` ink on dark. Orange keeps the warmth amber had at the cost of the error-red drift above, and its light badge label lands a hair under AA on the soft pill (about 4.4:1), the same wrinkle amber had. If the role ever needs to read as a true danger rather than a to-do, revisit the hue choice entirely, and rename the token to `--color-attention` if teal sticks.
